# GameCodex

GameCodex es un sitio web informativo e interactivo sobre videojuegos, desarrollado como proyecto final de la asignatura **Sistemas Colaborativos**.

El objetivo es crear un espacio donde los usuarios puedan explorar videojuegos, conocer sus características, descubrir recomendaciones y participar en actividades interactivas.

## Funcionalidades

El sitio contará con las siguientes secciones:

- **Inicio:** presentación de GameCodex y acceso a sus secciones.
- **Catálogo:** listado de videojuegos con búsqueda y filtros por género y plataforma.
- **Fichas de videojuegos:** información detallada de cada título.
- **Géneros:** información sobre los diferentes tipos de videojuegos.
- **Consolas y plataformas:** características de las principales plataformas de juego.
- **Recomendaciones:** tops y selecciones de videojuegos realizadas por el equipo.
- **Zona Gamer:** trivia interactiva sobre videojuegos.

También se contempla incorporar funcionalidades adicionales, como favoritos, reseñas, juegos similares y un comparador de plataformas.

## Tecnologías

Para el desarrollo utilizaremos:

- CSS3
- JavaScript
- Git y GitHub

## Organización del trabajo

El proyecto se desarrollará de manera colaborativa utilizando Git y GitHub para el control de versiones.

Cada integrante trabajará en ramas independientes para sus tareas. Los cambios se integrarán a la rama principal `main` mediante pull requests, después de ser revisados y aprobados.

Para organizar las actividades y dar seguimiento al progreso utilizaremos Trello, donde estarán registradas las tareas, responsables y fechas de entrega.

## Ejecución del proyecto

El sitio estará desarrollado principalmente con HTML, CSS y JavaScript, por lo que no requerirá instalar dependencias adicionales.

Una vez que esté disponible la estructura inicial, se podrá abrir `index.html` desde un navegador para visualizar la página.

## Estado del proyecto

Actualmente, GameCodex se encuentra en su etapa inicial de desarrollo.

La primera versión se enfocará en completar las funcionalidades principales del sitio. Posteriormente se incorporarán las mejoras adicionales según el avance del equipo.
